# orbitSim
Multi-level simulations for multiple body simulation
<br>
## sunEarth.py
A basic code to track the orbit of the earth and the sun, the units are in astronomical unit
<br>
## 2planet.py
A 3 body system with 1 sun and 2 planets, which can be of custom masses as factor of mass of the earth, and unit distance in terms of astronomical unit.
